# نظام إدارة العيادات الطبية

نظام متكامل ومتقدم لإدارة العيادات الطبية بميزات شاملة وسهلة الاستخدام.

## المميزات

### 🤝 إدارة المرضى
- سجل كامل للمرضى مع المعلومات الشخصية والطبية
- البحث المتقدم والتصفية
- السجل الطبي الكامل للمريض

### 📅 إدارة المواعيد
- جدولة المواعيد مع التحقق من التعارضات
- نظام تذكير بالمواعيد
- متابعة حالة المواعيد

### 💊 الوصفات الطبية
- إنشاء وتعديل الوصفات الطبية
- إدارة الأدوية والجرعات
- طباعة الوصفات بشكل منظم

### 🔬 المختبر والتحاليل
- طلبات التحاليل المخبرية
- تسجيل النتائج ومقارنتها بالقيم الطبيعية
- تقارير التحاليل الشاملة

### 💰 الفواتير والمحاسبة
- إنشاء الفواتير التلقائية واليدوية
- متابعة المدفوعات والحسابات
- تقارير مالية مفصلة

### 📊 التقارير والإحصائيات
- تقارير أداء العيادة
- إحصائيات المرضى والخدمات
- رسوم بيانية تفاعلية

### ⚙️ الإعدادات المتقدمة
- تخصيص كامل لإعدادات النظام
- إدارة المستخدمين والصلاحيات
- النسخ الاحتياطي والاستعادة

## التقنيات المستخدمة

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **التخزين**: IndexedDB (قاعدة بيانات محلية)
- **الرسوم البيانية**: Chart.js
- **التصميم**: CSS Grid, Flexbox
- **الأيقونات**: Font Awesome
